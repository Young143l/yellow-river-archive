# 文档索引

> 项目文档总入口。新增文档请同时在此登记。

## 目录约定

```
hmdev/
  docs/                 全部项目文档（含赛题原文）
  submission/           交付物（报名表；后期 docx / PPT / 视频 / rar）
  packages/data/        档案数据与清单（sites.yaml 等）
  apps/  packages/  tools/  harmony/    后期代码目录
```

整理规则：交付物一律进 `submission/`；参考资料与文档进 `docs/`；根目录不留散件。

## 维护规则

1. 改动架构、接口或流程后，同步更新《设计文档》对应章节
2. 每新增一项重要技术或管理决策，追加一条 ADR 到《决策日志》，编号连续
3. 每周会前更新《看板》的状态列与当前焦点
4. 交付材料（docx / PPT / 视频）**不得出现校名、师生姓名与 logo**（报名表除外）
