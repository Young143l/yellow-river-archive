## 2. 范围界定

### 2.1 做什么

| 层 | 内容 |
|---|---|
| 端侧（评分主体） | 80 条档案离线浏览、三维筛选与关键词检索、收藏笔记标签、分布式多端同步、知识图谱可视化、AI 问答客户端、备份恢复 |
| 云侧（增强） | 语义检索、图谱推理、AI 问答生成、个人数据云存储与同步中转 |
| 交付物 | 设计方案 docx、演示视频、PPT、rar 打包 |

### 2.2 明确不做

| 不做 | 原因 |
|---|---|
| 南向硬件与开发板 | 赛题属纯北向 |
| 自建账号体系 | 用华为 openid，兜底配对码 |
| 内容增量热更新 | 档案静态，随版本发布即可 |
| 多语言、社交分享、评论 | 与评分项无关 |
| Web 演示端 | 仅 P5 有余量时做 |
| UI 自动化测试 | 用 `devecocli ui` 手动验证并留截图 |
| CI 流水线 | 用本地 `.githooks` 替代 |
| 向量数据库 / 图数据库 | 规模不需要（ADR-005） |

## 3. 技术方案摘要

一句话：**离线优先的鸿蒙应用，云侧只做两件事——个人数据云存储与 RAG 检索问答服务**。

| 关键选择 | 结论 |
|---|---|
| 平台 | HarmonyOS SDK 26.0.0（API 26），`compatibleSdkVersion` = 17 |
| 生成模型 | DeepSeek 云 API（按 provider 抽象，可切换） |
| 嵌入与重排 | 阿里云百炼（text-embedding 1024 维 + Rerank） |
| 检索 | BM25（jieba + FTS5）+ 向量 → RRF → Rerank → 图谱增强 |
| 图谱 | SQLite 两表 + PageRank / 标签传播 / 最短路 |
| 同步 | 双通道：鸿蒙分布式数据服务（主）+ CloudSync（兜底） |
| 端侧检索 | 关键词 + 别名扩展 + 预计算关联（不做端侧语义检索） |

详见 [设计文档](./设计文档.md) 与 [决策日志](./decisions.md)。

## 5. 阶段与里程碑

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| **P0 地基** | 仓库骨架、数据契约、鸿蒙工程、四个技术验证 | 契约冻结、真机跑通空壳、四个验证有结论 |

| **P4 收藏笔记与同步** | 收藏笔记标签、双通道同步、备份恢复 | 双端冲突收敛、备份可跨设备恢复 |

## 9. 变更控制

| 情形 | 流程 |
|---|---|
| 范围新增（做原计划外的东西） | 提周会讨论 → 写入 [决策日志](./decisions.md) → 更新本文件 §2 |
| 技术方案变更 | 追加 ADR → 同步 [设计文档](./设计文档.md) 对应章节 |
| 接口 / 数据模型变更 | 走 [开发规范 §5](./开发规范.md) 的契约同步流程 |

## 10. 风险登记册

### 执行类风险

| 风险 | 影响 | 预案 |
|---|---|---|
| 第二台鸿蒙设备未落实 | 分布式双端同步无法演示（**主要功能**） | 尽早借或采购；应急用浏览器 Web 端或临时下载 tablet 镜像 |
| 报名材料未按时提交 | 失去参赛资格 | 10/30 前完成注册表 + 盖章扫描件 |
| 内容抄袭判定 | 取消资格 | 自行改写 + n-gram 查重（连续重合 ≤15 字） |
| 材料含校名 / 人名 | 取消资格 | 提交前关键词 lint 专项检查 |
| 数据生产超期 | 交付缩水 | 先 20 条精品打通，剩余按城市包干并行 |
| 三人进度不均 | 关键路径阻塞 | 周会同步；数据工作可互相补位 |

### 技术类风险

| 风险 | 影响 | 预案 |
|---|---|---|
| Account Kit 资质拿不到 | 身份绑定受阻 | IdentityAdapter 切配对码，不影响同步功能 |
| SDK 版本过高装不进演示设备 | 现场演示失败 | `compatibleSdkVersion` = 17；赛前用实际演示设备实测 |
| 路演现场断网 | AI 功能失效 | 四级降级链；演示视频作为备份 |
| 百炼 / DeepSeek 抖动或余额耗尽 | 演示中断 | provider 化 + 备用厂商 + 提前测好额度 |
| 2C2G 内存吃紧 | 服务抖动 | 预算控在约 200MB；配置 2G swap；上线前压测 |
