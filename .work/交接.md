## 4. 踩过的坑

**布局**
- `Canvas` / 背景图的 `height('100%')` 在 `Stack` 里被解析成**视口高度**，只盖第一屏 → 背景改挂 `backgroundImage` 到正文列
- 写死估算高度又会把 `Stack` 撑高，多出空白滚动 → 两者都不能用，`backgroundImage` 才是对的
- `TabContent` **默认居中对齐**子组件 → 列表只写 `width('100%')` 会浮在框中间，必须补 `height('100%') + justifyContent(Start)`
- `Tabs` 固定高度 560 会**裁掉**超出内容且无处滚动 → 每个 `TabContent` 包一层 `Scroll`

**组件**
- `@Prop` 不能叫 `enabled` / `padding`，与 `CustomComponent` 内置属性冲突直接编译报错
- `backgroundColor()` 的返回值类型写 `ResourceColor`，不能用 `string`（`Color.Transparent` 塞不进去）

**模拟器**
- `devecocli ui click` 用的是**设备像素**（本机 1256×2760），不是逻辑 1080×2400
- 标签栏实际在 y≈2553，不是 2700
- 应用会**恢复到上次所在的页面**，若停在 DetailPage 则无 tab 栏，返回键可能失效
- `devecocli emulator stop <名>` 后需等约 10 秒状态才变 stopped

**素材**
- 程序化画水墨事倍功半（走过宽色带→细线→多层描边→水波纹→青绿山水，评价依次「像蛇」「像鱼」「像电线」「太窄」「太宽」），最终用 AI 生成图 + 离屏合成
- 拼接痕迹的根因是**短距离交叉溶解盖不住河道错位**，必须离屏用 400px 过渡
