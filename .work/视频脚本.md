# 演示视频脚本 · 黄河图志

成片目标：**≤5 分 00 秒，≤100MB，mp4**。真机：华为畅享 90 Pro Max。

## 录制方式（强烈建议分段录）

用系统自带录屏：从右上角下拉控制中心 → 「屏幕录制」。每段单独录一个文件，录坏了只重录那一段，不用整片重来。

录完把这些文件放到 `~/Desktop/hmdev/.work/vid/`，文件名按下表编号（`01.mp4`…`10.mp4`），我用 ffmpeg 拼接、统一裁掉多余首尾、压到 100MB 以内。

录前 3 件事：
1. 关掉通知（设置 → 通知 → 临时关闭，或开勿扰），避免录进来消息弹窗
2. 桌面与壁纸不要出现校名、队名、人名、二维码；锁屏壁纸也检查
3. 输入法切到系统默认，避免候选词里出现个人姓名/昵称

## 时间轴与逐段操作

| 段 | 时长 | 屏幕动作 | 要点（画面上要看到什么） |
|---|---|---|---|
| 00 封面 | 8s | 静止放一张标题图（我可以现生成：作品名 + 一句话定位，无身份信息） | 「黄河图志 · 沿黄文化遗产的端侧优先数字档案」 |
| 01 首页长卷 | 30s | 打开 App → 首页，从顶部匀速下滚到底，再回顶 | 一条自西向东的河道长卷；四个时代分段（仰韶/夏商/宋/汉唐）依次划过；顶部显示「5 处遗址 · 4 个时代 · 5 座城市」 |
| 02 检索命中 | 30s | 点检索 → 输入「唐三彩」→ 出结果 → 点第一条 | 关键：**搜「唐三彩」出的是巩义窑址**，正文里命中的词要高亮；通道标签显示走了哪几路召回 |
| 03 别名扩展 | 15s | 清空输入「二里头文化」 | 命中的是「二里头遗址」，说明词典做了别名归一 |
| 04 详情页五层 | 35s | 从结果点进详情 → 依次点五个页签：图文介绍 / 考古发现 / 历史沿革 / 典故文物 / 相关诗词 | 每层停留 5-6 秒，能看到成段正文与配图；页面顶部点「收藏」图标 |
| 05 笔记与 Markdown | 30s | 详情页内进入笔记 → 半屏面板 → 用工具条插入标题、加粗 → 保存 | 保存后正文按 Markdown 渲染出来（标题分级、粗体生效），不是纯文本 |
| 06 知识图谱 | 35s | 切到图谱页 → 等布局稳定 → 点一个遗址节点 → 拖动平移一次 | 节点数量级 57 个、按簇着色；点中的遗址弹出带金色顶边的信息条；聚焦模式下邻居关系清晰 |
| 07 问答带引用 | 40s | 助手页 → 点一个示例问题（或输入「唐三彩的产地在哪里」）→ 等流式回答完成 → **点引用条目** | 回答下方列出引用编号，点进去能跳到对应原文段落。这是最加分的一段，务必让引用点开动作被拍到 |
| 08 断网降级 | 35s | 下拉控制中心开飞行模式 → 回助手页再问一次 | 界面给出原文摘要并明确标注「云端助手当前不可用」，**不报错、不白屏**；随后关掉飞行模式 |
| 09 同步与账号 | 40s | 我的页 → 登录（用户名 + PIN）→ 点「立即同步」→ 看进度条走完 → 显示同步完成时间 | 进度条要拍到走动过程；同步完成后收藏/笔记计数刷新 |
| 10 推荐与导出 | 25s | 回首页看「猜你想看」横排卡（带推荐理由文字）→ 我的页 → 导出档案文档 → 打开导出结果 | 推荐理由是人话（如「与你看过的聚落遗址同类」）；导出文档能打开、按时代与遗址编排 |
| 11 收尾 | 8s | 静止标题图 | 一行字：开源鸿蒙端侧 + 检索增强问答 + 分布式同步。无身份信息 |

合计约 4 分 56 秒（含 00 与 11）。**如果超时，优先砍 03 别名扩展（15s）和压缩 01 到 20s。**

## 每段的录法细节

- 操作节奏比平时慢半拍：每个点击之后停 1-2 秒再动，观众才看得清
- 滚动要匀速、一次到底，不要来回晃
- 每段开头先在目标页面静止 1 秒再开始操作，方便我裁
- 录一段就播一遍确认，别录完 12 段才发现全程没对上

## 同步那段（09）的两个方案

- **方案一（省事，推荐）**：只用真机录「登录 → 立即同步 → 进度条 → 完成」。跨设备互推不拍画面，靠 docx 里的测试记录支撑。
- **方案二（更有说服力，但要两台设备）**：真机 + 模拟器登同一账号，真机收藏后切到模拟器看它出现。需要额外装包与登录，时间紧就别选。
