# 蒯聩台遗址 来源摘录

蒯聩台遗址，位于河南省濮阳市华龙区帝丘路与建设东路交叉路口西北130米，距戚城遗址约3华里，总面积约6万平方米，现存台地约600平方米、高出周围地面7—10米。
1985-1987年，省文物研究所配合油田建设对遗址进行了科学发掘，发现了仰韶文化、龙山、晚商、春秋及汉代等时期的古文化遗存。2000年9月，蒯聩台遗址被河南省人民政府公布为省级重点文物保护单位。

蒯聩台遗址是一处新石器时代至汉代的古文化遗址。1985-1987年，省文物研究所配合油田建设，对遗址进行了科学发掘，发掘面积450平方米，发现了仰韶文化、龙山、晚商、春秋及汉代等时期的古文化遗存。2000年9月，蒯聩台遗址被公布为省级重点文物保护单位。

蒯聩台遗址位于戚城遗址东北约1.5公里处，原面积约6万平方米，现存台地高出地面约8米。遗址平面呈长方形，南北长260米、东西宽110米、周长740米。

蒯聩台遗址是一处新石器时代至汉代的古文化聚落遗址，历经多次考古勘探发掘，出土了大量珍贵文物，涵盖陶器、石器、骨器等各类器物。考古发掘出土的珍贵文物超过5000件。各时期文化层中的遗迹和遗物十分丰富。

1991年2月5日，中共中央总书记江泽民视察河南濮阳，讲解员孙德萱在介绍文物古迹时提及蒯聩台遗址。2000年9月，蒯聩台遗址被河南省人民政府公布为省级重点文物保护单位。经过开发，蒯聩台遗址成为市民休闲的街心公园，全天免费开放。

蒯聩台遗址文化内涵丰富，文化层自下而上叠压着仰韶文化、龙山文化、商、春秋及汉代等多个时期的遗存，对研究濮阳地区古文化发展序列和春秋战国时期卫国历史具有重要的历史和科学价值。

蒯聩是卫灵公的太子、孔悝的舅舅，因刺杀庶母南子未遂，逃到晋国避难。卫灵公去世后，蒯聩之子辄继位，是为卫出公。晋国的赵简子派阳虎将蒯聩护送回卫国，避身于此台，与儿子展开长达13年的君位争夺，即“父子争国”；蒯聩台之名由此而来。

公元前480年，蒯聩在其姐孔姬（又称伯姬，孔悝之母）和家臣浑良夫的帮助下劫持孔悝，逼走卫出公，自立为国君，史称卫庄公。子路闻讯，认为“食其禄不能避其难”，在抢救主人孔悝的战斗中遇难。蒯聩台遗址还是《左传》所载晋郑铁丘之战的战略要地，与周边的戚城遗址、子路墓祠、西水坡遗址遥相呼应，共同串联起濮阳春秋至秦汉时期的历史文脉。

河南省濮阳市华龙区帝丘路与建设东路交叉路口西北130米。
