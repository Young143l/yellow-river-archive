# 巩义窑址 来源摘录

巩义窑址，位于河南省郑州市巩义市东约5公里白河两岸，涵盖水地河村、白河村、铁匠炉村及大、小黄冶村等区域，为全国重点文物保护单位。该窑址创烧于北魏，隋代突破白瓷技术，唐代以白瓷、三彩瓷及青花瓷闻名，是唯一已知的唐青花产地，其中薄胎白瓷质地精细，《新唐书·地理志》所载“开元贡白瓷”可能产于此地。
2001年，黄冶唐三彩窑址被中华人民共和国国务院公布为第五批全国重点文物保护单位。2006年，周边白河两岸窑址并入后更名为巩义窑址，巩义窑址被中华人民共和国国务院公布为升格为第六批全国重点文物保护单位。
考古发掘出土白釉点画蓝彩瓷片及唐青花标本，与扬州唐城遗址、“黑石号”沉船文物相印证，为研究青花瓷起源提供关键实证。相关学术研讨会进一步确认巩义窑为唐青花发源地，巩义窑遗址博物馆开馆运营。
巩义窑址是“十一五”期间全国100处大遗址之一，由国家文物局、财政部实施重点保护。

巩义窑址创烧于北朝（北魏时期），发展于隋，唐代达到鼎盛，宋金后渐衰。唐代巩义窑是河南府贡白瓷的产地，《新唐书·地理志》所载“开元贡白瓷”可能产于此地。

其产品通过海上丝绸之路远销海外，广州、扬州及“黑石号”沉船出水文物证实了其外贸地位。巩义窑是目前唯一已知的唐青花产地，2002-2004年黄冶窑址发掘出土唐青花残片，与扬州唐城遗址和“黑石号”沉船文物特征一致，证实其为唐青花发源地。

巩义窑址位于河南省郑州市巩义市东约5公里的白河两岸，分布在水地河村、白河村、铁匠炉村、大黄冶村、小黄冶村等区域，总面积约16万平方米，主要包括黄冶窑址（属站街镇）和白河窑址（属北山口镇）。

该窑址发现于1957年，由北京故宫博物院冯先铭等首次调查；1976年河南省文物工作队对黄冶窑址进行了首次试掘；2002年至2007年，河南省文物考古研究院与中国文化遗产研究院合作，相继对黄冶窑和白河窑址进行了系统考古发掘，清理出窑炉、作坊等遗迹，出土了大量唐三彩、白瓷、黑瓷和青花瓷等遗物。

巩义窑产品种类丰富，包括青瓷、白瓷、黑釉瓷、黄釉瓷、唐三彩、唐青花、绞胎瓷等。

巩义窑白瓷是唐代中原地区制造水平最高的白瓷，为文献记载的“开元贡白瓷”产地。白瓷产品可分为粗、细两类，器型以碗、盘、碟、盂、盆、砚、粉盒、罐、注子、瓶、枕等日用器皿为主。代表性文物有“白瓷塔盖瓶”。

巩义窑是生产唐三彩的主要窑址，其产品不仅供应洛阳、西安，还通过水路外运。唐三彩制品可分为日用器皿、陶塑小品、大型俑类、模型明器和建筑构件五大类，制作工艺为先制坯素烧，再上釉二次烧成。代表性文物如“三彩鹅衔梅花杯”。

巩义窑是目前唯一已知的唐青花产地。2002-2004年考古在唐代地层出土白釉蓝彩器和唐青花残片。唐青花开创中国青花釉下彩装饰先河，其钴料可能来自中东，纹饰受异域影响，产品多外销。代表性文物如“蓝釉点彩水注”，巩义窑遗址出土的唐代青花瓷器与扬州唐城遗址及“黑石号”沉船文物特征高度吻合，形成完整证据链。

巩义窑又称巩县窑，是古代巩义地区窑场的总称。其肇始于汉，发展于北魏，成熟于隋，鼎盛于唐，因工艺精湛、产品种类众多，在中国陶瓷史上占有极其重要的地位。唐代，我国制瓷业形成了“南青北白”的局面，巩义窑白瓷是北方白瓷的代表与精品。巩义窑不仅是唐代中原地区白瓷制造水平最高的窑口，还是文献记载河南府开元年间贡白瓷（“开元贡白瓷”）的产地。巩义（黄冶窑）是目前中国发现最早、规模最大的生产唐三彩的专业窑口，被誉为“唐三彩的故乡”。巩义窑是唐青花的发源地，考古发现证实巩义窑是目前唯一已知的唐青花产地。其在中晚唐时期烧制的青花瓷，开创了中国青花釉下彩装饰的先河，为后世青花瓷的繁荣奠定了基础。出土的唐青花瓷器与扬州唐城遗址及“黑石号”沉船发现的青花瓷特征一致，形成了完整的证据链。

巩义窑址是全国重点文物保护单位，同时也是国家文物局、财政部“十一五”期间重点保护的全国100处大遗址之一。

关于巩义窑址的名称，此前文物界也没有统一的称谓，除了黄冶唐三彩窑址因为研究、发掘得比较早，名称比较响以外，其他的名称还有巩义瓷窑址、巩义瓷窑遗址、巩义三彩窑址，也有专门针对某一部分的名称，如白河瓷窑址、小黄冶村、大黄冶村窑址等。2006年，国务院在公布第六批全国重点文物保护单位时，将以上名称进行合并，统一定名为“巩义窑址”。巩义窑址不是一座窑炉，而是坐落于巩义市东方5千米、白河两岸的一系列民间窑厂，其中还包括了曾经被列入第五批全国重点文物保护单位的黄冶三彩窑址。位于大、小黄冶村的黄冶窑最早被发现，作为唐三彩的确定产地，很早就得到了重视。随后，在周围的水地河村、白河村、铁匠炉村都发现了窑址。鉴于这一系列窑厂建筑构造的相似性、产品工艺的相关性，整体被命名为巩义窑址，合并成为第六批全国重点文物保护单位。

近年来，巩义市实施了巩县窑遗址公园项目，该项目位于窑址核心区域，以2002年至2004年发掘的8座窑址作为保护展示对象，建设集遗址保护、遗址展示等功能为一体的多功能展馆，旨在保护唐三彩烧制技艺、展示千年窑场文化内涵，并带动旅游、餐饮、住宿等产业发展，促进就业和经济增长，打造巩义文化地标。

2025年5月18日，巩义窑遗址博物馆盛大开馆运营，馆内陈列唐三彩鸭衔梅花杯、唐青花瓷片等珍品。巩县窑遗址公园项目位于巩义窑址核心区域，以2002年至2004年发掘的8座窑址作为保护展示对象，目前内部展示已完成总体建设进度的97%。

2025年5月23日至8月31日，“丝路华章——唐代青花瓷瑰宝展”在河南南水北调博物馆持续展出。2024年11月10日至2025年3月9日，“中原出海——巩义窑与海上丝绸之路”展览在广州南汉二陵博物馆展出。
