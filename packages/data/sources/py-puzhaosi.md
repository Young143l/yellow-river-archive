# 普照寺大雄宝殿 来源摘录

清丰普照寺大雄宝殿位于河南省清丰县城西南隅，是普照寺（原名圆明寺）内仅存的古建筑，为河南省文物保护单位。该殿建于明成化二十一年（1485年），面阔五间，进深三间，单檐庑殿顶覆绿琉璃脊，殿内现存铜佛、泥塑罗汉及浮雕壁画等。
普照寺始建于唐上元元年（760年），元至元十九年（1282年）改今名，后历经毁坏与复建。1933年寺址曾改为中山公园，1938年遭战火破坏，1949年后曾为县委办公地。1986年，大雄宝殿被公布为省级文物保护单位并进行修缮。

普照寺原名圆明寺，始建于唐上元元年（674年），元至元十九年（1282年）改为普照寺，元末毁于兵燹。

明洪武年间进行复修，并建天王殿、水陆殿等二百余间，现存的大雄宝殿则建于明成化二十一年（1485年）。

中华民国二十二年（1933年），普照寺被改为中山公园，辟建戏楼、假山、月牙河等设施，1938年园内建筑遭日寇破坏。1949年，中共清丰县委迁于此处办公。

1980年，大雄宝殿被公布为县级文物保护单位，1986年被公布为省级文物保护单位，并拨款进行了全面修葺。

2008年8月，少林寺正式接管普照寺，并将其作为下院。

大雄宝殿建于明成化二十一年（1485年），面阔五间，进深三间，面积248.92平方米，单层庑殿式，绿彩琉璃脊顶。殿面前壁由朱漆木格扣合，殿内为纵四横六合抱明柱排列。正面铸有丈高铜佛三尊，四周泥塑罗汉十八尊。四壁浮雕唐僧西天取经故事。内顶作圆形图案，沥粉金龙四条，正中绘有八卦图，显示明代中期佛道两教相结合的趋势。整个大殿设计严雅，彩绘秀丽，工艺精美。

普照寺大雄宝殿的保护工作始于1980年，被公布为县级文物保护单位。1986年，升格为省级文物保护单位，并拨款15万元进行修葺，用木70余方，使大殿重现明代木构建筑雄姿。2008年少林寺接管后，对寺院殿堂、念佛堂等设施进行布置完善，迎请了诸多佛像，添置法鼓、报钟。2012年6月，大雄宝殿全堂佛像贴金完毕。

2008年8月，应清丰县人民政府及清丰县民族宗教局的邀请，少林寺正式接管了普照寺，并将其作为少林寺驻北地区的下院，寺院作为宗教活动场所对外开放。自接管以来，寺院殿堂、念佛堂等佛教设施相继布置完善，恢复了晨钟暮鼓的悠悠古韵。

2008年至2012年，普照寺多次举办大型法会，并传授在家居士三皈五戒及菩萨戒。2015年8月16日，举行了瑜伽焰口超度法会。寺院僧团严守净戒，积极促进社会和谐安定，并配合当地政府宣传孝道文化，筹集善款资助癌症患者、失学儿童及灾区难民。同时，多次接待国外游客，配合旅游局、文化局完成接待任务。寺院现任主持为释延逢法师。
