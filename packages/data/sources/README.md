# 来源摘录

每个条目一个文件，命名为 `<itemId>.md`（与 `packages/data/sites/<itemId>.yaml` 对应）。

## 为什么要这个文件

三个用途，缺一不可：

1. **给 AI 起草提供依据** —— 起草脚本读这份摘录，避免无中生有
2. **给人改写提供对照** —— 知道原文长什么样，才好做句式重组
3. **给质检提供比对基准** —— `pnpm data:lint` 用它做 n-gram 查重，连续重合 ≥15 字直接判错

## 格式

```markdown
# <条目名> 来源摘录

## 来源 1：中国大百科全书·考古学
- URL: https://...
- 访问日期: 2026-10-05

<原文关键段落，可整段摘抄（这是来源，不是作品）>

## 来源 2：国家文物局 · 全国重点文物保护单位名录
- URL: http://...
- 访问日期: 2026-10-05

<原文关键段落>
```

## 注意

- 摘录可以逐字照抄——**它是来源，不是作品**
- 但写进 `sites/<id>.yaml` 的正文必须改写，与摘录连续重合不超过 15 字
- 每条约 3-5 个来源，覆盖：基本信息、考古发现、历史事件、文旅信息
