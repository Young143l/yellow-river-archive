# 开封东大寺 来源摘录

开封东大寺，俗称东大寺，位于河南省开封市顺河区清平南北街7号，是河南规模较大的清真寺，始建年代不详，清道光二十六年（1846年）重修。
开封东大寺坐西朝东，呈中轴线对称布局，东西长159.78米，南北宽50.6米，占地面积8085平方米。共有三进院落，现存山门、东西厢房、二门、东西配房、礼拜大殿、东西配殿、沐浴室等建筑。开封东大寺是河南省历史悠久、规模宏大、保存完整的一处伊斯兰教建筑群，寺院内各配套设施如经堂、沐浴室、礼拜大殿等齐备，体现出完整的民族宗教仪式及生活习俗，是一部生动形象的伊斯兰教民俗教科书。
2006年5月25日，开封东大寺被中华人民共和国国务院公布为第六批全国重点文物保护单位。

明洪武元年（1368年）三月，朱元璋亲笔题写“精忠尚武”的条幅悬挂在大殿内，并下令翻修。

明永乐五年（1407年），明成祖朱棣“敕赐增修”开封东大寺。

清顺治十二年（1655年），掌教曹明，教中人郭鹿鸣、李尚仁等重返故里寻找开封东大寺的遗址，倡导众人募捐重修。

清康熙二十八年（1689年），开封东大寺重建。

清道光二十一年（1841年），开封东大寺被黄河水灾毁坏。

清道光二十六年（1846年），重修开封东大寺的大门、卷棚和二殿等，将御赐“护国清真”匾额悬挂大门正中。

清光绪二十六年（1900年），开封东大寺重修。

2018年12月8日，开封市非物质文化遗产武术项目传承保护研讨会在开封东大寺举行。

开封东大寺坐西朝东，呈中轴线对称布局，东西长159.78米，南北宽50.6米，占地面积8085平方米。共有三进院落，现存山门、东西厢房、二门、东西配房、礼拜大殿、东西配殿、沐浴室等建筑。

山门为硬山顶建筑，面阔五间，进深三间，占地面积128.7平方米。明间门楣正中悬挂穆青手书“东大寺”匾额。柱础为多层式。屋面覆绿色琉璃瓦，正脊正中琉璃饰件上有“敕建清真寺”字样。

二门为中柱式硬山顶建筑，面阔三间，进深两间，绿色琉璃瓦覆顶。

礼拜大殿由前厅、中殿、拜殿三部分勾连而成，室内空间宽敞，能同时容纳数百人举行宗教仪式。前厅为卷棚歇山式建筑，面阔五间，进深一间。中殿为硬山顶建筑，面阔五间，进深两间。前设隔扇门，鼓式柱础。其后檐柱与拜殿前檐柱合一，两山砌封护墙。屋面覆绿色琉璃瓦，正脊当中有铜质火焰宝瓶。拜殿为硬山式建筑，面阔五间，进深三间。两山封护墙上各辟一个券门，外有垂花门楼，以供通行及采光、通风。后檐墙内壁明间设壁龛，供奉阿拉伯文经典。外壁檐部为砖仿木构，仿制出椽、飞、一斗两升交麻叶头斗栱、平板枋、额枋、雀替、垂花柱等构件，并饰以雕刻，题材多为花草、锦纹等，工艺考究。屋面亦为绿色琉璃瓦，正脊中立有高大的火焰宝瓶，顶端饰星月。

开封东大寺自明永乐五年（1407年）重修以来，一直是开封回族的文化传承中心，尚武健身之风盛行不衰，保留大量武术功力项目，武术套路、器械套路更是数以百计，群众基础深厚，是中华武术传承发展的原生态区域。这里已经申报的传统体育类非物质文化遗产有4项，其中国家级1项（石锁）、省级1项（黄派查拳）、市级2项（耍砘子、抛接沙袋）；准非遗项目更多，且涉及食品、习俗、文艺、服饰、节庆等方面。东大寺武术馆，历史悠久，影响深远，是享誉国内外的武术传统基地。

1989年3月29日，伊朗伊斯兰共和国驻华大使布鲁杰迪率团来开封东大寺访问。同年5月17日，马来西亚驻华大使、夫人和该国穆斯林协会会长率团来寺访问。

1992年3月29日，伊朗诵经团到开封东大寺诵经，交流文化。另外，还有美国、加拿大、德国、日本和阿拉伯国家的国际友人来参观访问。

开封东大寺是河南省历史悠久、规模宏大、保存完整的一处伊斯兰教建筑群，寺院内各配套设施如经堂、沐浴室、礼拜大殿等齐备，体现出完整的民族宗教仪式及生活习俗，是一部生动形象的伊斯兰教民俗教科书。

2006年5月25日，开封东大寺被中华人民共和国国务院公布为第六批全国重点文物保护单位。

2000年，开封东大寺被评为全国百座“模范清真寺”之一。

2014年，开封东大寺被评为全国“模范和谐寺观教堂”。

开封东大寺位于河南省开封市顺河区清平南北街7号。
