# 偃师商城遗址 来源摘录

偃师商城遗址，古称西亳，位于河南省洛阳市偃师区城区西约1千米，总面积约2平方千米，是商代第一座都城遗址。
偃师商城遗址是迄今为止发现的商代早期城址中年代最早、规模最大、保存最完好的一座，内有大型宫殿建筑和军事防御设施，城内的排水设施完备，护城壕、排水沟、大渠一应俱全，街道纵横，王城、府库、兵营、城门排列井然有序。
偃师商城遗址平面呈长方形，由宫城、小城和大城三重城垣及多组宫殿建筑基址组成。它是分两期建成的，先建了一座小城，大约过了五六十年后，又建了一座大城。遗址内出土了陶器、玉器、石器、骨器、蚌器、原始瓷器等。该遗址对古代经济、政治、文化、社会、生态、科技，尤其是考古学、历史学、建筑学、水利设施和园林等领域的研究具有重要的学术意义。
1988年1月13日，偃师商城遗址被中华人民共和国国务院公布为第三批全国重点文物保护单位。

偃师商城的建成年代约为前16世纪至前14世纪，3600多年的历史。前16世纪，商汤灭夏建立商朝。商汤攻进夏都后，决定在夏都附近另建新都，并从南亳迁此，史称西亳。

1983年，国家“七五”重点建设项目——“洛阳首阳山火力发电厂”在选址过程中进行了地下文物勘探，中国社会科学院考古研究所汉魏故城工作队的考古学家在偃师县城西郊勘探时，意外发现地下1~4米深处，埋着一座古代城池。

1984～2016年，I号基址群（J1，即宫城）进行了挖掘。

1996～1997年，小城城墙进行了发掘与确认。

1991～1994年、2002年，II号基址群（J2）进行了勘探与发掘。

2007年3月至2008年8月，考古人员对大城西城墙沿线进行了全面勘探，并选择了4个地点进行考古发掘工作。

2011年10月开始，考古人员对宫城区南部的一号、三号与七号、五号与六号等建筑基址进行了复查。

2018～2023年，考古人员基于地理信息系统推进的资料梳理与发掘工作，确认了小城西北部仓储设施的分布状况，多次确认城墙内外两侧均有道路。

2020年10月起，中国社会科学院考古研究所河南第二工作队对偃师商城遗址内的多处水道遗存展开了发掘工作。

2021~2023年，考古人员开展了系统的发掘工作，探明了II号基址群的四至，并对部分建筑基址进行了重点挖掘。

2024年，在偃师商城宫城东西两侧和南侧的多个地点发现了2处城门、道路和排水沟渠等城市要素。

偃师商城遗址北靠邙山，南濒（古）洛河，背山靠河，地势平坦开阔，扼守着洛阳盆地开阔地带的交通要道，在军事和经济上都有较大的作用。内有大型宫殿建筑和军事防御设施，城内的排水设施完备，护城壕、排水沟、大渠一应俱全，街道纵横，王城、府库、兵营、城门排列井然有序，是商代早期城址中年代最早、规模最大、保存最为完好的一座帝都。偃师商城遗址平面呈长方形，南北长1700余米，中部宽约1120米，总面积约2平方千米，由宫城、小城和大城三重城垣及多组宫殿建筑基址组成。偃师商城是分两期建成的，先建了一座小城，大约过了五六十年后，又建了一座大城。
偃师商城遗址分布图(截至2023年)

小城临洛河，面积约为80万平方米，面朝后市，择中立宫，对称布局，城南部地势略高处为宫城和官署区，国库位于城西南隅，铸铜作坊位于城外东北河边，普通居住区和手工业作坊主要分布在城的北部。在大城修建过程中，小城城墙虽然有削减的现象，但是主要集中在小城南墙、西墙和北墙西端等改扩建部分，而小城北墙的中段与东段、东墙的中段与北段则未进行削减，墙体在偃师商城使用期间高出地表，城墙两侧也经常作为埋葬地点，墙体所具有的封闭、区划和防御功能未丧失。小城城墙外没有防卫意义上的护城壕。小城城墙内外两侧均存在道路，已经具备环城路和顺城路中间夹城墙的特征。主要包括核心区、贮藏区、其他建筑基址区和手工业遗存区等。

大城是在小城的基础上建立起来的，由夯土筑成，南部城墙与小城南城墙重合，并以此向北、东延伸，扩展而成，平面呈“刀”形，面积也扩大到了约190万平方米。大城在保持原有格局基础上，对大多数宫殿进行了扩建或重建，呈现出盛世景象。大城有城门五座，北城墙一座、东西城墙各有两座，两两相对。大城西墙北段新发现了1座城门，编号为西三城门。在西二城门以南，大城西墙和小城北墙内侧发现了5个南北向排列的“亚”字形建筑基址，在西一城门外发现了位于护城壕西侧的石砌水道和其西端的水源地——南北向古河道。在护城壕内发现了与石砌水道东西——线分布的两排柱础（应该是连接护城壕两侧水道的渡槽类设施的支撑柱遗迹）和护城壕底部窄沟两侧的南北向柱础石（每侧6个柱础石，应该是此处桥梁设施的支撑柱遗迹）。据此判断，在此处应该存在着由护城壕、渡槽和桥梁设施共同构成的立体的水利和交通设施。

宫城大体呈方形，外围有宽约2米的夯土围墙，由南向北分为宫殿区、祭祀区、池苑区三部分。宫殿建筑则分为东西对称的两区，是商王施政、处理国家大事的地方，其建筑格局多为后代帝王所参照；祭祀区设置考究，仅猪牲就有近百头之多；池苑区是商王休闲娱乐的地方，其中心为一长约130米、宽20米的长方形水池，是人工挖掘并用自然石块堆砌而成的，系中国考古发现的最早引水造景工程，也是最早的城市园林遗址。考古发掘表明，宫城经历了始建、扩建和改建三个阶段。早期宫城大致呈正方形，面积约3.6万平方米；晚期向西、南扩建后面积约4.9万平方米。宫城处于小城内南北向三列空间的中路偏南部。宫城的位置，内部建筑基址的规模、构造和空间分布方式都体现出其为偃师商城的核心功能区。

考古发现偃师商城小城区域内至少存在着两条东西向的水渠。宫殿区的雨水通过这些排水沟被引流至外侧的主干沟渠，沿着主干渠道而出。大城西墙附近的一条水渠呈现出东西向的沟槽状，宽度达到了2.7米，两侧各砌有半米宽的石块，底部则铺设了石板，形成了一处明渠。其残存深度约为0.75米，展示了古代水利工程的较高技艺。宫殿区外的东北部，考古发掘出了一处早年被发现的倒“几”字形水道的拐角部位。其修筑方式为：先开挖出深深的沟槽，然后在内部两侧巧妙地垒砌石块形成狭窄的水腔，再在水腔上部铺设石块作为遮盖，使其完全隐藏于地下。偃师商城拥有商代最早最完备的城市水系，城市明暗水渠结合，内外水系贯通，营造了一处约2600平方米的池苑景观，承担着以水护城，排水防涝的功能。

偃师商城遗址宫殿区在原址上方模拟重建宫城区内的4号、2号、8号等宫殿，位于宫城区中部的商朝早期王室贵族祭祀遗址群，皇家池苑和宫墙墙体砖砌也已模拟展示。整个展示工程覆盖在原遗址上方，距地下遗址数米，所有建筑均悬空建设，其中4号宫殿是主体建筑，这座宫殿高约10米，东西长约51米，南北约宽32米，坐北朝南，东、西、南面均配套以回廊，属于“四合院”式的封闭式宫殿建筑，包括正殿、庭院、东庑、西庑、南庑、南门和西侧门等7部分，其中正殿在基址北部，平面长方形，东西长36.5米，南北宽11.8米，建于高出当时地面0.4米的夯土台基上，殿顶属四面坡顶，回廊外用柱子支撑凸出来挑檐，上端设有重檐，屋顶全部被茅草覆盖，即“四阿重屋”（四坡顶、两重檐）、“茅茨土阶”。展示区核心是御苑内的人工水池，东西长约130米，南北宽约20米，深约1.5米，周边用石块护砌，池塘东西两侧各有一条水道，西侧为注水渠道，东侧为排水渠道，池塘与水渠总长约1430米。西渠起于西护城河，通过西城门下的石质沟渠把水注入池塘。东侧水渠的部分段落已发掘展示，渠上铺有规整的石板，经东城门底部把水排入东护城河。这是中国古代自秦汉以来以太液池为中心的御用池苑的最早先例。

偃师商城遗址是中国早期都城遗址代表之一，是中华五千年文明重要的物证。该遗址的发现证实了汉唐文献中记载的商汤灭夏后，于“夏墟”建造都城这一事件的真实性，同时也解决了教科书上关于商的起源等问题。偃师商城建筑艺术总结了中国自仰韶文化晚期以来造城经验，宫城及其内的宫殿建筑，是研究中国早期帝王都城，尤其是宫城制度、宫城建筑布局的宝贵资料。偃师商城遗址对古代经济、政治、文化、社会、生态、科技，尤其是考古学、历史学、建筑学、水利设施和园林等领域的研究具有重要的学术意义。

1988年1月13日，偃师商城遗址被中华人民共和国国务院公布为第三批全国重点文物保护单位。

2004年，偃师商城遗址列入全国首批公布的36处大遗址保护名单。

2006年3月，国家文物局批复了《偃师商城遗址保护利用总体规划》。

2021年10月12日，偃师商城遗址入选国家文物局《大遗址保护利用“十四五”专项规划》“十四五”时期大遗址”名单。

1983年，偃师商城遗址被联合国教科文组织列为世界十七大发现之一。

1997年，偃师商城遗址小城考古当选当年全国十大考古新发现。

2001年，偃师商城遗址被评为中国20世纪百项考古大发现之一。

2021年9月，偃师商城遗址被评选为河南考古百年百大考古发现。

偃师商城遗址位于河南省洛阳市偃师区城区西约1千米。

公交线路：偃师区乘坐806路（偃师——二里头博物馆——洛阳龙门高铁站）、807路（偃师——二里头博物馆——洛阳汽车站），可以到达偃师商城遗址。
