# 仓颉陵 来源摘录

仓颉陵文化旅游景区位于河南省南乐县梁村乡史官村，是国家AAAA级旅游景区，景区内有仓颉陵墓、庙宇及仰韶、龙山时期古文化遗址。仓颉陵是中华文明的重要发祥地之一，仓颉被尊为“三教之祖”、“万圣之宗”。史官遗址为全国重点文物保护单位，景区也是省级爱国主义教育基地和中小学社会实践教育基地。每年农历正月举办的仓颉庙会是豫北地区最大的庙会之一，2015年被列入省级非物质文化遗产名录。景区入选了河南省“夏爽中原•老家河南”文化旅游线路和文化和旅游部黄河主题国家级旅游线路。

仓颉陵文化旅游景区是景区的名称。景区所在的古文化遗址根据国家文物局规定，以所在地村名命名为“史官遗址”。

南乐仓颉庙始建于东汉永兴二年（154年），最初为仓颉祠。北魏时期被兵火焚毁，唐代重建仓颉庙，更名为“史皇圣庙”。新中国成立后保存的建筑多为明清两代重建。“文化大革命”期间，陵前的古建筑群及石坊、石狮、翁仲等遭到严重破坏。1977年秋，原安阳地区文管会调查确认此处为一处古文化遗址。1999年和2017年，考古工作者对遗址进行发掘勘探，确认其为以龙山文化为主，包含仰韶文化晚期至商周时期遗存的古文化遗址。2000年，仓颉陵遗址被河南省人民政府公布为省级文物保护单位。2019年10月，史官遗址（仓颉陵）被国务院公布为全国重点文物保护单位。

2007年11月，举办了首届仓颉汉字文化节。2009年7月，南乐被中国民间文艺家协会命名为“仓颉文化之乡”。2016年10月，景区被评为国家AAA级旅游景区。2023年12月，南乐县仓颉陵文化旅游景区被河南省文化和旅游厅评定为国家AAAA级旅游景区。2023年，南乐县委、县政府委托北京九鼎辉煌旅游规划设计有限公司制定《南乐县仓颉陵文化旅游景区提升规划》。

景区建设工程于2019年开工，主要庙外主要建设广场、停车场、公共厕所、立面改造等，现已完工；庙内主要建设角楼、掖门、配殿、藏甲楼、碑亭等，角楼已完工，现正在建设庙内掖门、4座配殿及藏甲楼。

仓颉陵文化旅游景区位于河南省濮阳市南乐县城西北20公里处的梁村乡史官村（原名吴村）。景区占地面积约36000平方米（54亩），遗址平面呈近圆形，东西长240米，南北宽210米，面积约5万平方米。地上为仓颉陵墓及庙宇建筑群，地下为仰韶文化、龙山文化至商周时期的古文化遗址。

仓颉陵为圆锥形土冢，高约5米（一说20米），围墙周长36.5米，分12节，象征一年365天和12个月，当地有绕陵三周的习俗及“儿女草”传说。仓颉庙始建于东汉永兴二年（154年），现存建筑为明清时期重建，包括朝天门、仰圣门、万古一人殿、六书殿、藏甲楼等。

万古一人殿为庙内正殿，系明代建筑，内供仓颉四目金身塑像，殿内悬挂北宋名臣寇准所题楹联“盘古斯文地，开天圣人家”。藏甲楼是庙内最高建筑，三间两层，绿琉璃瓦盖顶。故宅井位于仓陵与仓庙之间，相传为仓颉故宅饮水用井。

石雕群包括字圣坊、石狮、石鸮、翁仲等，其中字圣坊刻有“天雨粟 鬼夜吟”，翁仲为明代遗存。

仓颉文化博物馆馆藏从遗址出土的仰韶文化红陶钵、彩陶钵，龙山文化石凿、骨锥、陶罐等文物，并设有文字发展历程互动展。

仓颉湖是景区内水域，设有游船项目，为庙会期间亲子游玩的热门去处。

仓颉陵文化旅游景区每年农历正月举办仓颉庙会。该庙会是豫北地区最大的庙会之一，于每年农历正月初一至二十四举行，并于2015年被列入省级非物质文化遗产保护名录。

庙会活动丰富多元，融合了民俗巡游、非遗展演（如打铁花）、特色美食、文创展销、新春祈福、传统戏曲、互动游戏（猜字谜、猜枚大赛）、游乐场、灯光秀等元素。例如，在2026年第四届南乐民俗文化节期间，仓颉庙会以“拜仓颉·游南乐”为主题，于腊月二十六至正月初六举办，累计接待游客34.2万人次，创历史新高。

除仓颉庙会外，景区每年还定期举办谷雨祭仓颉、汉字文化节、仓颉文化节（通常在11月左右）等重要传统文化活动。

民间有拜谒陵墓时绕陵三周的习俗，以及关于“儿女草”的传说。

2007年举办首届仓颉汉字文化节，2009年南乐县被命名为“仓颉文化之乡”，景区举办谷雨祭仓颉、汉字文化节等活动。景区是省级爱国主义教育基地、省级中小学社会实践教育基地，设有研学路线。

2014年，景区被命名为市级“爱国主义教育基地”。2015年，仓颉庙会被公布为省级非物质文化遗产保护名录；同年，被省委宣传部命名为“特色文化基地”。

2020年，景区入选河南省文旅厅“夏爽中原·老家河南”四条文化旅游线路中的“古都名城·亲子研学游”；同年，申报省级“河南省中小学生社会实践教育基地”（于2023年挂牌）。2021年，入选文化和旅游部发布的10条黄河主题国家级旅游线路中的“黄河寻根问祖之旅”；同年，仓颉文化博物馆荣获全省第八批“爱国主义教育基地”。

仓颉陵文化旅游景区为国家AAAA级旅游景区。

门票价格为30元/人，学生可享半价优惠，研学团队另有优惠。建议游玩时间为2-3小时。景区提供专业讲解服务，费用约为50元/次。

游客可选择自驾前往，或从南乐县城乘坐前往梁村乡的班车，在史官村下车后步行约5分钟可达。

游客可搭配游览南乐县城老街，以规划更充裕的半日行程。

面向全国优待证持证人提供免费入园优惠。
